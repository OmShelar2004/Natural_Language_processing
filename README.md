# NLP Learning Journey with Python

## Overview

This repository documents my hands-on journey of learning Natural Language Processing (NLP) using Python.

The repository contains beginner-friendly exercises, preprocessing techniques, regex-based text extraction tasks, and mini NLP pipelines that build the foundation for advanced topics such as TF-IDF, Word Embeddings, Text Classification, RAG Systems, and Large Language Models (LLMs).
