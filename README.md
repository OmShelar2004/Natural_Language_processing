# NLP Preprocessing Practice with Python

## Overview

This repository contains beginner-friendly NLP (Natural Language Processing) preprocessing exercises implemented in Python.

The goal of this project is to build a strong foundation in text preprocessing, which is an essential step in Machine Learning, Deep Learning, RAG Systems, and Large Language Model (LLM) applications.

---

## Topics Covered

### 1. Text Normalization

* Convert text to lowercase
* Remove punctuation
* Remove numbers

### 2. Tokenization

* Split sentences into words
* Basic text segmentation

### 3. Stopword Removal

* Remove common words that carry little semantic meaning
* Custom stopword filtering

### 4. Word Frequency Analysis

* Count occurrences of words
* Identify the most frequent word

### 5. Stemming

* Reduce words to their root form
* Porter Stemmer implementation using NLTK

### 6. Mini NLP Pipeline

Complete preprocessing workflow including:

* Lowercasing
* Punctuation removal
* Number removal
* Tokenization
* Stopword removal
